# Single-cell RNA-seq and TCR Repertoire Analysis of MAIT Cells in Bacterial Lung Infections

Disclaimer: This README was generated using AI. The code in the repository was not generated by AI except for minor occasional assistance.

This repository contains analysis code for single-cell RNA sequencing and T-cell receptor (TCR) repertoire profiling of Mucosal-Associated Invariant T (MAIT) cells from mouse lungs infected with *Acinetobacter baumannii* or *Francisella tularensis*.

## Overview

MAIT cells play a crucial role in antimicrobial immunity. This project investigates the transcriptional and clonal landscape of MAIT cells in response to two distinct bacterial lung infections at 7 days post-infection (DPI), compared to uninfected controls.

### Experimental Design

- **Groups**:
  - Uninfected control (CT): 4 mice
  - *F. tularensis* infection: 5 mice (7 DPI)
  - *A. baumannii* infection: 4 mice (7 DPI)
- **Sorting**: Single-cell sorted MAIT cells (TCRβ+, MR1:5-OP-RU tetramer+)
- **Multiplexing**: TotalSeq-C hashtag antibodies for sample multiplexing
- **Platform**: 10x Genomics Chromium Single Cell 5' v2
- **Cell counts**:
  - CT: ~9,100 cells
  - *F. tularensis*: ~26,000 cells
  - *A. baumannii*: ~52,000 cells

## Analysis Pipeline

### 1. Data Processing (`scripts/Processing.qmd`)
- Cell Ranger output loading and preprocessing
- Hashtag demultiplexing (HTODemux)
- Quality control filtering
  - Low-quality cell removal
  - Doublet detection and removal
  - Contaminating macrophage cluster removal
  - Damaged cell identification (DropletQC)
- SCTransform normalization
- Dimensionality reduction (PCA, UMAP)
- Leiden clustering
- Cell cycle scoring and regression

### 2. Main Analysis (`scripts/Analysis.qmd`)
- Cluster annotation using SingleR (ImmGen reference)
- Differential expression analysis
- Signature scoring (UCell)
- Exploratory visualizations

### 3. TCR Repertoire Analysis (`scripts/Manuscript_TCR_repertoire_analysis.qmd`)
- TCR sequence processing (scRepertoire)
- Clonotype definition using paired CDR3 sequences (α and β chains)
- Diversity metrics (D50)
- Clonotype size distribution
- TCR overlap analysis between samples
- TRBV-TRBJ pairing visualization (circlize)

### 4. Advanced Analyses
- **Pseudobulk differential expression**: DESeq2-based analysis across conditions
- **Consensus NMF (cNMF)**: Gene program identification (15 components)
- **Differential abundance**: MiloR neighborhood analysis
- **Pathway enrichment**: ClusterProfiler with GO/KEGG/MSigDB

### 5. Figure Generation (`scripts/Manuscript_figures.qmd`)
- Publication-ready figures using cowplot/patchwork
- Generates both PDF and SVG formats

## Dependencies

This project uses R 4.5.1 with package management via `renv`. Key packages include:

- **Single-cell analysis**: Seurat (v5.3.0), scRepertoire (v2.5.7), scCustomize
- **TCR analysis**: scRepertoire, circlize, immunarch
- **Differential expression**: DESeq2 (v1.48.2), presto
- **Pathway enrichment**: clusterProfiler (v4.16.0), enrichplot, msigdbr
- **Annotation**: SingleR, celldex (ImmGen)
- **Quality control**: scDblFinder, DropletQC
- **Dimensionality reduction**: cNMF (python-based, via reticulate)
- **Visualization**: ggplot2, cowplot, patchwork, viridis, pheatmap

### Setup

1. Clone this repository
2. Install R 4.5.1
3. Open R in the project directory and run:
   ```r
   renv::restore()
   ```
4. Python 3.9.6 is required for cNMF analysis
5. **Data access**: Raw sequencing data must be obtained separately (see Data Availability section below). Place Cell Ranger outputs in a `data/` directory in the project root.

## Running the Analysis

The analysis is designed to be run sequentially:

1. **Processing**: `scripts/Processing.qmd` - Generates QC'd Seurat objects
2. **Exploration**: `scripts/Analysis.qmd` - Exploratory data analysis
3. **TCR Analysis**: `scripts/Manuscript_TCR_repertoire_analysis.qmd` - TCR repertoire
4. **Figures**: `scripts/Manuscript_figures.qmd` - Generate publication figures

All scripts are Quarto documents (.qmd) that can be rendered to HTML reports:
```bash
quarto render scripts/Processing.qmd
```

**Note**: HTML outputs and intermediate results are not tracked in version control. Running the scripts will generate these files locally in your working directory.

## Methods Reference

Detailed methods are documented in `Methods.qmd`, which generates the Materials and Methods section for the manuscript. Key methodological details:

- **Cell Ranger**: v9.0.1 with GRCm39-2024-A reference
- **Clonotype definition**: Paired CDR3 amino acid sequences (α and β chains)
- **Diversity metric**: D50 (fraction of clonotypes accounting for 50% of sequences)
- **Clustering resolution**: 0.375 (with cell cycle regression, 30 dimensions)
- **Statistical thresholds**: Adjusted p-value < 0.05, log2FC threshold of 0.3-1 (analysis-dependent)

## Experimental Notes

- Initial genotyping issue: Some planned CT mice were actually CMT mice, reducing CT group from 8 to 4 mice
- CMT mice were kept separate and confirmed by lack of MAIT cells on FACS
- Hashtag labeling: CT and *A. baumannii* samples received hashtags 1,2,4,5; *F. tularensis* received 1-5 (hashtag 3 ran out)
- Sort duration: 3.5 hours for 9.75 mL (~2.75 mL/hour, ~3.66 mice/hour for lung sorting)
- Gating was strict on MAIT cells based on the CT group
